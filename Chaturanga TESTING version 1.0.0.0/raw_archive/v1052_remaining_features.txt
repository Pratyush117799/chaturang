2. CRITICAL MOMENT DETECTION — seer additions
═══════════════════════════════════════════════════════
Files: new js/analysis-worker.js + additions to seer.html/seer.js

analysis-worker.js (Web Worker):
- Receives: { positions: [{fen-like state, moveHistory, playerIndex}], botELO: 400 }
- For each position, runs ChaturangaTieredBot.getMove(game, 400)
- Compares material delta of bot's suggested move vs actual move made
- If delta difference >= 3 points (Ashwa=3, Ratha=5, Danti=3, Raja=∞), flag as missed win
- Returns array of { moveIndex, actualMove, betterMove, deltaGap, pieceType }

seer.js additions:
- After game loads in Seer, spawn analysis-worker with blunder positions
- In move log, add gold lightning ⚡ icon next to blunder moves
- On click: expand panel showing "Bot found [piece] to [square] — would have won [X] material"
- Draw gold arrow on board at the missed move square
- Section heading: "Turning Points" above the move log

4. MOVE NOTATION + SHARE URL — js/cn-encoder.js + additions
═══════════════════════════════════════════════════════
cn-encoder.js:
- Define Chaturanga Notation (CN) format: R:e1-e5 B:e8-e5x A:d4-f5 Y:pass
  Player initials R/B/G/Y, from-to, x=capture, p=promotion, f=forfeit
- encodeCN(moveHistory) → compact string
- decodeCN(string) → moveHistory array
- toShareURL(moveHistory) → base64 encode CN, append as ?game=BASE64 to current URL
- fromShareURL() → check window.location.search for ?game=, decode if present

Seer integration:
- Add "Share game" button in game-over overlay (copy existing button style)
- On click: call toShareURL, copy to clipboard, show "Link copied" toast
- On seer.html load: call fromShareURL(), if found auto-load the game into replay
