Integration Guide
How to use these pieces in game.html / board renderer:

Each piece SVG uses two CSS variables for colorisation:
  --pc : main piece fill colour (set per player)
  --pc2 : highlight / jewel colour (lighter tone of --pc)
  --pc3 : shadow / engraving detail (darker tone)

In your board square renderer, wrap the piece SVG:
<div class="piece piece-red"> ... SVG ... </div>

CSS player theming:
.piece-red { --pc:#e04030; --pc2:#f8a090; --pc3:rgba(0,0,0,0.45); }
.piece-blue { --pc:#3070d0; --pc2:#90b8f8; --pc3:rgba(0,0,0,0.45); }
.piece-green { --pc:#30a050; --pc2:#90d8a0; --pc3:rgba(0,0,0,0.45); }
.piece-yellow { --pc:#c8a010; --pc2:#f8d870; --pc3:rgba(0,0,0,0.45); }

All pieces use viewBox="0 0 60 90" — render at any size with
width="48" height="72" for a standard 64px square board cell.
