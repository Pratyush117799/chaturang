Integration into ui.js

In renderBoardGrid(), replace the Unicode text span with this SVG element. Set the two hex values — player colour for petals and the ♞ text — from the existing playerColours[owner] array. The viewBox is 80×80; at a 54px square use width="50" height="50", at 40px use width="38" height="38". No clipPath, no CSS variables needed — the SVG is self-contained and safe to repeat for every piece on the board. The ♞ character is a standard Unicode chess symbol present in every OS font stack since 2004.
