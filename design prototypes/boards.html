Chaturanga — Board Prototypes
युद्ध क्षेत्र  ·  The Field of War  ·  Four Armies, One Board
Four unique 8×8 Ashtapada boards with authentic Indian warfare aesthetic — each with a distinct visual personality and watermarked tile patterns. Plus five extended board sizes: Dasapada (10×10) through 18×18. Each board is a pure SVG/CSS grid with no external assets required.
Ashtapada — अष्टपद   8×8
Four prototypes, each unique in color palette, tile watermark motif, and border character. All boards share the same 70 px square size and grid structure — drop-in swappable in the same renderBoardGrid() call. Army corner zones (2 rows × 4 cols each) carry a very subtle tint matching their army colour.
1 · Kurukshetra Kshetra — कुरुक्षेत्र
Deep blood crimson and aged amber-gold. Lotus mandala on light squares, 8-spoke Ashoka Chakra on dark. Double gold frame with corner lotus ornaments. The darkest and most battle-worn of the four — evokes the stained stone of Kurukshetra after the 18-day war.
2 · Pushkar Mandala — पुष्कर मण्डल
Saffron gold and midnight indigo. Trishul trident on light squares, radiant Surya sun disc on dark. Ornate jewelled frame. The most spiritual — the board as a sacred yantra, the game as cosmic ritual. Strongest contrast of the four.
3 · Mauryan Rajya — मौर्य राज्य
Warm sandstone and dark granite slate. Elephant silhouette on light squares, Dharmachakra on dark. Stone-cut linear frame. The imperial board — referencing Ashoka's carved Sanchi pillars and the great stone chess pieces unearthed at Taxila.
4 · Vana Samragya — वन साम्राज्य
Sage jungle green and deep forest dark. Peacock feather eye on light squares, lotus bud on dark. Vine-leaf border. The most organic — inspired by the forest kingdoms of ancient India, where armies trained under jungle canopy before marching to Kurukshetra.
Extended Board Sizes
Five larger board variants for extended Chaturanga rulesets. Each maintains the Kurukshetra color palette as a base (for visual consistency across ruleset variants) but with adjusted square sizes. The grid structure scales identically — only cols, rows, and squarePx change.
Dasapada — दशपद   10×10
56 px squares · 560 px total. Adds 2 outer rows/cols — allows wider army deployments and richer opening formations.
Vrihadapada — बृहदपद   12×12
47 px squares · 564 px total. Referenced in some Puranic texts as the board of the celestial war game played between Devas and Asuras.
14×14 — चतुर्दश
40 px squares · 560 px total. Each army occupies 3 rows × 5 cols. Ratha movement advantage greatly increases at this size.
16×16 — षोडश
36 px squares · 576 px total. Two additional piece types per army possible at this scale — historical "Maha-Chaturanga" variant.
18×18 — अष्टादश
32 px squares · 576 px total. Largest historical board variant — 4 armies of 18 pieces each. Epic campaign format.

1 · Board Configuration Object
// Drop into ui.js / game.js
const BOARD_CFG = {
  cols: 8, rows: 8,
  squarePx: 70,
  // Inner grid area (no frame offset needed
  // when using CSS-grid board — origin is 0,0)
  originX: 0,
  originY: 0,

  // Convert game coords → pixel position
  toPixel(row, col) {
    return {
      x: this.originX + col * this.squarePx,
      y: this.originY + row * this.squarePx,
    };
  },
  // Convert pixel click → game coords
  toCell(px, py) {
    return {
      col: Math.floor((px - this.originX) / this.squarePx),
      row: Math.floor((py - this.originY) / this.squarePx),
    };
  },
};
2 · renderBoardGrid() — Replace Existing
function renderBoardGrid(boardId, cfg = BOARD_CFG) {
  const el = document.getElementById(boardId);
  el.innerHTML = '';
  el.style.cssText = `
    display: grid;
    grid-template-columns: repeat(${cfg.cols}, ${cfg.squarePx}px);
    grid-template-rows: repeat(${cfg.rows}, ${cfg.squarePx}px);
    position: relative;
    width: ${cfg.cols * cfg.squarePx}px;
    height: ${cfg.rows * cfg.squarePx}px;
  `;
  for (let r = 0; r < cfg.rows; r++) {
    for (let c = 0; c < cfg.cols; c++) {
      const cell = document.createElement('div');
      cell.className = 'board-cell '
        + ((r + c) % 2 === 0 ? 'light' : 'dark');
      cell.dataset.row = r;
      cell.dataset.col = c;
      cell.style.width = cfg.squarePx + 'px';
      cell.style.height = cfg.squarePx + 'px';
      cell.style.position = 'relative';
      cell.addEventListener('click', e => onCellClick(r, c, e));
      el.appendChild(cell);
    }
  }
}
3 · Placing Pieces on the Board
// Place an SVG piece element on the board
function placePiece(boardEl, pieceSvgStr, row, col, cfg) {
  const wrap = document.createElement('div');
  const { x, y } = cfg.toPixel(row, col);
  const pad = cfg.squarePx * 0.08; // 8% padding
  const sz  = cfg.squarePx - pad * 2;
  wrap.style.cssText = `
    position: absolute;
    left: ${x + pad}px;
    top:  ${y + pad}px;
    width: ${sz}px;
    height: ${sz}px;
    pointer-events: none;
    z-index: 5;
  `;
  wrap.innerHTML = pieceSvgStr;
  const svg = wrap.querySelector('svg');
  if (svg) {
    svg.setAttribute('width', sz);
    svg.setAttribute('height', sz);
  }
  boardEl.appendChild(wrap);
  return wrap;
}

Switching Board Sizes at Runtime
const BOARD_SIZES = {
  '8x8':   { cols:8,  rows:8,  squarePx:70, name:'Ashtapada'  },
  '10x10': { cols:10, rows:10, squarePx:56, name:'Dasapada'   },
  '12x12': { cols:12, rows:12, squarePx:47, name:'Vrihadapada'},
  '14x14': { cols:14, rows:14, squarePx:40, name:'14×14'      },
  '16x16': { cols:16, rows:16, squarePx:36, name:'16×16'      },
  '18x18': { cols:18, rows:18, squarePx:32, name:'18×18'      },
};

// In your game init:
function initGame(sizeKey) {
  const cfg = { ...BOARD_SIZES[sizeKey], originX:0, originY:0,
    toPixel(r,c){ return {x:c*this.squarePx, y:r*this.squarePx}; },
    toCell(px,py){ return {col:Math.floor(px/this.squarePx), row:Math.floor(py/this.squarePx)}; }
  };
  window.BOARD_CFG = cfg;
  renderBoardGrid('game-board', cfg);
  setupArmies(cfg);  // place pieces according to board size
}
Army placement note: For all board sizes, each of the 4 armies occupies the 2 rows closest to their corner × 4 columns wide. For 8×8 that's rows 0–1 cols 0–3 (top-left army), rows 0–1 cols 4–7 (top-right), rows 6–7 cols 0–3 (bottom-left), rows 6–7 cols 4–7 (bottom-right). For larger boards, extend army deployment zones proportionally: 3 rows × 5 cols for 14×14+.
