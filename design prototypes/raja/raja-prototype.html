⬡ Integration as a Game Piece

The Raja is delivered as a self-contained SVG circle (viewBox 0 0 240 240) — a coin-medal with the character painted inside. Drop it as an <img>, inline <svg>, or CSS background-image. On the board, the container cell simply wraps it in a fixed square div and the SVG fills it automatically via width:100%; height:100%.

Resizing: Because the piece uses a vector viewBox (no pixel dimensions baked in), it renders crisply at any size — from a 34 px thumbnail in a move log to a 300 px hero card on a piece selection screen. For a standard 8×8 Chaturanga board with 80 px cells, render at 72 px (90% of cell width) with a 4 px gap for breathing room. The circular shape naturally prevents visual overlap with adjacent cells.

Color theming: Swap the army color by changing two CSS variables on the wrapping element — --turb-start and --turb-end — and every gradient inside that references them shifts instantly. No JS needed. The gold rings, skin tones, gems, and beard stay constant across all four armies; only the turban and garment shift to the army hue.

Hover & selection states: Add filter: drop-shadow(0 0 12px var(--army-glow)) on :hover and a scale(1.08) transform for a satisfying pick-up feel. For a selected/active piece, apply a pulsing @keyframes glow on the outer gold ring stroke to communicate the piece is in play.
